
# Task 3 - Password Complexity Checker

## About the Project

The Password Complexity Checker is a web application that
evaluates password strength based on common security criteria.

## Features

- Checks password length
- Checks uppercase and lowercase letters
- Checks numbers and special characters
- Displays password strength
- Provides suggestions to improve password security
- Includes show/hide and clear password options
- Evaluates passwords in the browser without storing them

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation

Install the required dependency:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Security Note

This project provides a basic password strength estimate.
It does not verify whether a password has been exposed in a data breach.
Do not enter your real account password into a demo application.
