# Task 3 - VaultCheck Password Complexity Checker

## About
VaultCheck is a password complexity checker that helps users evaluate password strength and generate random passwords.

## Features
- Password strength checker
- Password security checklist
- Password generator
- Copy generated password
- Show and hide password
- Responsive user interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run
1. Install dependencies using `pip install -r requirements.txt`
2. Run `python app.py`
3. Open http://127.0.0.1:5000
