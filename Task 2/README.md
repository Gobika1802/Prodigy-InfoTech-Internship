# Task 2 - Pixel Image Encryption

## Project Description
Pixel Image Encryption is a Python-based project that encrypts and decrypts images using a user-provided key.

## Technologies Used
- Python
- Flask
- Pillow (PIL)
- HTML
- CSS

## Features
- Upload an image
- Encrypt the image using a key
- Decrypt the image using the same key
- Download the processed image

## How to Run
1. Install the required dependencies.
2. Run `py app.py`.
3. Open the local Flask website in your browser.
4. Upload an image and enter an encryption key.
